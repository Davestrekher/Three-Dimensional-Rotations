# Three-Dimensional-Rotations
Rotações tridimensionais implementadas em java e renderizadas pelo JavaFX, oferecendo comparações de benchmark
entre multiplicação de matrizes e quatérnios

## Requisitos
Certifique que o JavaFX está instalado no ambiente. De preferência, utilize o Java 8.

## Compilar
Na raiz do projeto, execute:
javac Main.java

## Executar
Na raiz do projeto, execute:
java Principal
